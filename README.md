# Speech-Recognition-System
Speech Recognition System is a Python-based desktop application that provides intelligent voice processing capabilities through an easy-to-use graphical interface. The system enables users to convert text into speech, recognize spoken words as text, perform real-time speech recognition, and store recognized results in a MySQL database. Built using Python, Tkinter, and speech processing libraries, this project demonstrates the practical implementation of speech recognition technology for desktop applications.

✨ Features

🎤 Speech to Text Conversion

🔊 Text to Speech Conversion
⚡ Real-Time Speech Recognition
💾 Save Recognized Speech Results
📂 View Saved Results
🖥️ User-Friendly Tkinter GUI
🗄️ MySQL Database Integration


🛠️ Technologies Used

Python
Tkinter
SpeechRecognition
PyAudio
pyttsx3
MySQL
mysql-connector-python


🎯 Project Objective

The objective of this project is to develop a user-friendly speech recognition system that allows users to interact with a computer using voice commands. It combines speech recognition and text-to-speech technologies to improve accessibility, productivity, and hands-free interaction in desktop applications.
